# 你好，我是 Ralf

我是湾区的一名资深软件工程师，做前端和全栈 Web 开发。最近几年在 **Tubi** 做增长，在**阿里巴巴**做协同文档，两款产品都有上亿用户。我最看重性能、用户体验和研发效率。

**正在寻找新的工作机会**：资深前端或全栈岗位，湾区或可搬迁。最方便的联系方式是 [LinkedIn](https://www.linkedin.com/in/weikang-zhang)。

[个人网站](https://ralfz.com/zh/) · [博客](https://blog.ralfz.com/) · [LinkedIn](https://www.linkedin.com/in/weikang-zhang) · [English](https://github.com/RalfZhang)

## 工作经历

**Tubi** · 2022–2025\
负责一个拥有 1 亿用户的流媒体平台的新用户引导与增长前端。通过 A/B 测试把注册率从约 40% 提升到约 60%；把 LCP 从 4.2 秒降到 2.5 秒，CLS 从 0.48 降到 0；为团队搭建了 ESLint 规则、Storybook 和 CI 等工具。

**阿里巴巴** · 2019–2022\
参与打造钉钉文档，一个用户超过 1 亿的企业协同文档平台。设计了它的分享与权限系统，并封装成 SDK 供其他产品团队接入；还为钉钉（用户超过 7 亿）开发了消息组件。

**更早** · 2014–2019\
在 WTOIP 和 Kuaizi Tech 做前端，在 Kuaizi 写了后来被团队采用的 MVVM 框架 [Zender](https://github.com/RalfZhang/Zender)。职业生涯从 Moonew 的全栈开发起步，用的是 ASP.NET 和 SQL Server。

## 项目

- **[InkCity](https://github.com/RalfZhang/ink-city)**：你的桌面壁纸，每天换成一座不同城市的路网地图。基于 Tauri，用 Rust、React 和 TypeScript 编写，支持 macOS、Windows 和 Linux。（[开发复盘](https://blog.ralfz.com/2026/10/07/ink-city-app/)）
- **[CSTU 课程报名平台](https://short.cstu.cloud)**：California Science and Technology University 正在使用的课程报名平台，由我主导开发：Next.js、Prisma、PostgreSQL 和 Stripe，部署在 GCP Cloud Run 上。（[代码](https://github.com/CSTU-dev/cstu-short-term-course-website)）
- **[File Template](https://marketplace.visualstudio.com/items?itemName=RalfZhang.filetemplate)**：一个 VS Code 扩展，让每个新文件都从模板开始，文件头和样板代码一应俱全。自 2017 年发布以来安装量超过 36,000 次。
- **[FoxAuth](https://github.com/FoxAuth/FoxAuth)**：能自动填充 TOTP 验证码的 Firefox 身份验证器，弹窗界面和自动填充由我开发。
- **[微豆 Vdo](https://github.com/RalfZhang/Vdo)**：用 Material Design 重做的单页版豆瓣，基于 Vue，260+ Star。（[教程](https://blog.ralfz.com/2017/04/04/vdo/)）
- **[大笨钟 Big Ben](https://github.com/RalfZhang/big-ben)**：社交网络上的钟楼。每到整点：咣！同时发到豆瓣、Threads 和 Mastodon。
